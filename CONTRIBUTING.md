# Contributing to safeway-coupons

**Contributions are welcome!**

Thank you for your time and interest in improving
**safeway-coupons**!

* **Web site**: **<https://smkent.github.io/safeway-coupons>**
  for general project information, usage, and development documentation

## LLM use

A contributor is always the author of their contributions.
You must read, review, and understand everything you submit, including
LLM-generated code or text, and be able to explain it on request.
Contributions must be submitted by a person, not autonomously by a bot or
LLM agent.

If a commit contains code or text largely generated by an LLM, add an
`Assisted-by: <tool>:<model>` trailer to its message. This can be done
automatically with `git commit --trailer="Assisted-by: <tool>:<model>"`.

Do not use `Co-authored-by:` for LLM attribution. LLMs are tools, not authors.
Do not include LLM session URLs, or promotional lines such as
"Generated with [...]."
